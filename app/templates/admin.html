Capture starts and stops on its own inside each window. If it is already running when a window opens, it keeps running and stops at the window’s end. Pressing Stop during a window holds it until the next scheduled start. Starting by hand outside a window is never stopped by a schedule. Windows that overlap or touch run as one session.
Times follow the time zone you pick, including daylight saving. The machine and the relay must be running for a schedule to fire; a window already under way when the relay starts is picked up, and one missed entirely is skipped.

Blocked words
Edited in blocklist.txt with one word or phrase per line. Changes to the file are picked up within about two seconds, no restart. You can also edit it here.
Matches are removed outright: no asterisks, no gap, nothing on screen to notice. Case and accents are ignored (nino matches niño) and only whole words match, so ass will not touch class.
Each feed is filtered on its own, so to remove a word everywhere, list it in each language.
Recordings & export
A recording covers exactly one run — from Start capture to Stop. Every committed caption line is written to disk as it happens, so a crash mid-event still leaves you the transcript up to that point. Blocked words are removed before anything is written. Off by default: nothing is recorded until you turn this on.

Appearance & tuning
A caption line is committed once its text has been quiet for line break after silence and it ends on a sentence boundary. A line that never reaches one is committed by the force a line break backstop, always at a word boundary so a word is never cut in half. Lower the first for snappier lines; raise the second if you see a sentence split across two lines. In-progress text is already on screen as it streams, so a generous backstop costs nothing. Changing these restarts live sessions. gpt-realtime-translate fixes phrase boundaries server-side, so these two fields are the only line-break controls.
