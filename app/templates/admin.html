Translation engine

Realtime runs one translation session per language. Text transcribes once and has a text model translate each finished line into every language, so extra languages cost almost nothing. Captions then arrive a line at a time, a second or two behind. Changing it restarts live sessions.

What’s in the export

The zip holds a timestamped transcript-<LANGUAGE>.txt per language, plus, per target language, a pairs-<TARGET>.jsonl (each source line matched to its translation, with a confidence field) and a finetune-<TARGET>.jsonl in OpenAI chat format, ready to upload to a fine-tuning job.
The two feeds carry no shared segment id and are broken into lines independently, so pairs are matched on overlapping time span and every row says how sure the match is. Only the exact ones are carried into the fine-tuning file — the rest stay in the pairs file to be reviewed.

How schedules work

Capture starts and stops on its own inside each window. If it is already running when a window opens, it keeps running and stops at the window’s end. Pressing Stop during a window holds it until the next scheduled start. Starting by hand outside a window is never stopped by a schedule. Windows that overlap or touch run as one session.
Times follow the time zone you pick, including daylight saving. The machine and the relay must be running for a schedule to fire; a window already under way when the relay starts is picked up, and one missed entirely is skipped.

Planning Center

Follow the service plan and show it on panels.

Connection

Make a Personal Access Token at api.planningcenteronline.com/personal_access_tokens and paste its application ID and secret here. Everything Relay does in Planning Center, including Next and Previous from a panel, runs as the person who made the token and only within their permissions. The secret is stored server-side in config.json, never shown again, and never written to the log, an export or a recording. Until a token is saved, Relay does not contact Planning Center at all.

ProPresenter

Follow the slide that is up, show lyrics on screens and panels, and put a message on the stage display.

Connection

In ProPresenter, open Settings → Network, switch Enable Network on, and copy the port it shows: the port is set per install, so Relay assumes none. ProPresenter’s API has no password, so Relay only ever talks out to the address typed here, and anyone who can reach that port can control ProPresenter: keep it on the production network. If Relay runs in Docker, the container must be able to reach that address and port (allow it in the firewall of the ProPresenter machine), and Find on this network cannot see it from inside Docker Desktop: type the address.

Timers on panels

A caption panel set to Timers shows ProPresenter timers large: white while one runs, amber and then red as a countdown nears zero, and red with a minus sign once it is over. The panel counts the seconds itself between Relay's updates. A panel can use its own settings instead: open it under Panels.
Time left, as minutes:seconds (2:00) or seconds (90). Red cannot be earlier than amber.

Slide-note tags

A tag in a slide's notes in ProPresenter does something in Relay when that slide goes live. Relay only reads the notes, it never changes them. [relay:lyrics] on a slide, or [relay-deck:lyrics] in any slide of a presentation for every slide of it that has no tag of its own. The tags are capture-start, capture-stop (Relay's own captioning, not ProPresenter's capture), lyrics, captions, lang=es and alert=Button name. The guide has the full list.
A slide's tags run only after it has stayed live this long, so a fast run through the slides runs one set, not all of them. Moving to a slide with the same tags runs nothing again.

Blocked words

Removed from the transcript and every translation.

Blocklist

Edited in blocklist.txt with one word or phrase per line. Changes to the file are picked up within about two seconds, no restart. You can also edit it here.

How matching works

Matches are removed outright: no asterisks, no gap, nothing on screen to notice. Case and accents are ignored (nino matches niño) and only whole words match, so ass will not touch class.
Each feed is filtered on its own, so to remove a word everywhere, list it in each language.

Appearance & tuning

Viewer text size and how caption lines are broken.

Viewer display

Caption line breaks

A caption line is committed once its text has been quiet for line break after silence and it ends on a sentence boundary. A line that never reaches one is committed by the force a line break backstop, always at a word boundary so a word is never cut in half. Lower the first for snappier lines; raise the second if you see a sentence split across two lines. In-progress text is already on screen as it streams, so a generous backstop costs nothing. Changing these restarts live sessions. gpt-realtime-translate fixes phrase boundaries server-side, so these two fields are the only line-break controls.
