    Audio bus

    Up to 32 lanes from any input, routed to outputs through one crosspoint matrix.

    What’s in the export

    The zip holds a timestamped transcript-<LANGUAGE>.txt per language, plus, per target language, a pairs-<TARGET>.jsonl (each source line matched to its translation, with a confidence field) and a finetune-<TARGET>.jsonl in OpenAI chat format, ready to upload to a fine-tuning job.
    The two feeds carry no shared segment id and are broken into lines independently, so pairs are matched on overlapping time span and every row says how sure the match is. Only the exact ones are carried into the fine-tuning file — the rest stay in the pairs file to be reviewed.

      How schedules work

      Capture starts and stops on its own inside each window of the schedules ticked for it. If it is already running when a window opens, it keeps running and stops at the window’s end. Pressing Stop during a window holds it until the next scheduled start. Starting by hand outside a window is never stopped by a schedule. Windows that overlap or touch run as one session.
      Times follow Relay's time zone, including daylight saving. The machine and the relay must be running for a schedule to fire; a window already under way when the relay starts is picked up, and one missed entirely is skipped.

      Blocked words

      Removed from the transcript and every translation.

      Blocklist

      Edited in blocklist.txt with one word or phrase per line. Changes to the file are picked up within about two seconds, no restart. You can also edit it here.

      How matching works

      Matches are removed outright: no asterisks, no gap, nothing on screen to notice. Case and accents are ignored (nino matches niño) and only whole words match, so ass will not touch class.
      Each feed is filtered on its own, so to remove a word everywhere, list it in each language.

      Appearance & tuning

      Viewer text size and how caption lines are broken.

      Viewer display

      One time zone for Relay: schedules, signage, boards, call times and YouTube all read it.

      Caption line breaks

      A caption line is committed once its text has been quiet for line break after silence and it ends on a sentence boundary. A line that never reaches one is committed by the force a line break backstop, always at a word boundary so a word is never cut in half. Lower the first for snappier lines; raise the second if you see a sentence split across two lines. In-progress text is already on screen as it streams, so a generous backstop costs nothing. Changing these restarts live sessions.
