REAPER

Record the service in REAPER: start and stop with the stream or a schedule, drop a marker for each song, and get warned when no track is armed, an expected track is missing or a track goes silent.

In REAPER, open Settings > Control/OSC/web, click Add and choose OSC (Open Sound Control). Set the mode to "Configure device IP + local port", the device IP to this computer's address (127.0.0.1 when REAPER runs here), the device port to the listen port below (9001), and the local listen port to the port below (8000). Keep the pattern config on Default, then click OK and Apply.
