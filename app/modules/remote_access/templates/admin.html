Remote access

An internet link to the captions and translations, for people who aren't on this network.

Remote viewer link

This link opens the same viewer pages as the room's link: the captions, the translations and the presentation screens. The operator panel is never reachable through it. Anyone who has the link can watch, so share it the way you'd share a livestream link.
Switching Remote access off on the Modules page stops the link and keeps the address, so the same link works again when you switch it back on. Releasing gives the address up for good; enrolling again needs a new code and gives a different link.

Enroll this install

Enrolling gives this install its own address on relaychurchsystems.com. Relay connects out to Cloudflare, so nothing changes on your router or firewall. The audio never leaves this computer; only the viewer pages are served through the link.
