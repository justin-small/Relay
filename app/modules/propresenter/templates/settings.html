ProPresenter

Follow the slide that is up, show lyrics on screens and panels, and put a message on the stage display.

Connection

In ProPresenter, open Settings → Network, switch Enable Network on, and copy the port it shows: the port is set per install, so Relay assumes none. ProPresenter’s API has no password, so Relay only ever talks out to the address typed here, and anyone who can reach that port can control ProPresenter: keep it on the production network. The ProPresenter machine’s firewall must let this computer reach that port.

Lyrics feed

Song lyrics are licensed. The feed is off for the public phone viewer unless you switch it on, and anyone on the network who opens the link can read it when it is on.
A presentation is a song when its file is in this library, or when its parts are named Verse, Chorus, Bridge and the like.

Timers on panels

A caption panel set to Timers shows ProPresenter timers large: white while one runs, amber and then red as a countdown nears zero, and red with a minus sign once it is over. The panel counts the seconds itself between Relay's updates. A panel can use its own settings instead: open it under Panels.
Time left, as minutes:seconds (2:00) or seconds (90). Red cannot be earlier than amber.
Tick up to four. With none ticked, panels show the first four timers ProPresenter has.

Stage message

An alert can also appear here: tick Also show on the ProPresenter stage display on its button under Alerts. It is cleared when the alert is acknowledged.

Slide-note tags

A tag in a slide's notes in ProPresenter does something in Relay when that slide goes live. Relay only reads the notes, it never changes them. [relay:lyrics] on a slide, or [relay-deck:lyrics] in any slide of a presentation for every slide of it that has no tag of its own. The tags are capture-start, capture-stop (Relay's own captioning, not ProPresenter's capture), lyrics, captions, lang=es and alert=Button name. The guide has the full list.
A slide's tags run only after it has stayed live this long, so a fast run through the slides runs one set, not all of them. Moving to a slide with the same tags runs nothing again.

Planning Center link

Matches the plan's items to ProPresenter's presentations, shows both sides while a service runs, and can let ProPresenter move Planning Center's LIVE item. Both switches are off until you turn them on. Needs ProPresenter and Planning Center connected.
