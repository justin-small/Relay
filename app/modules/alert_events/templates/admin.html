Alert events

Tell other products when an alert or stage message is sent, and when an alert is acknowledged (with the reply, if one was picked).

Webhook

Relay POSTs a JSON body: event (alert.sent, alert.acknowledged, alert.ended or message.sent), button, from, level, targets, and on an acknowledge seen_on, seen_after_s and reply.

OSC

UDP. /relay/alert/sent button, from, level · /relay/alert/acknowledged button, seen on, reply · /relay/alert/ended button, state (missed or cancelled) · /relay/message/sent text, from, level.

Bitfocus Companion

Companion reads alert state from GET /api/admin/alert-events/state with an API token. It returns variables (alerts_on, last_event, last_reply, and <button>_state, _from, _seen_on, _reply for each alert button) and feedbacks (the buttons that are flashing, seen, not seen or replied to), for a Companion button to light on.
