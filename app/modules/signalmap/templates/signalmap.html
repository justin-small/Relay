Signal map

Paste the patch list and see each line against the live Dante routing: is the channel on the network, does anything receive it, and does that subscription resolve. Works with Dante devices. With the Dante module off the list shows as pasted, without the live column.

Patch list

One channel per line: CH, NAME, PORT, SOCKET, UPSTREAM, separated by commas, tabs or bars. A first line naming the columns is used when present. Relay matches NAME to a Dante transmit channel's name (or name@device); the other columns are shown as written.
