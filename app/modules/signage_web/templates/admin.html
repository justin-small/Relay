Web & YouTube

Save a web page or a YouTube video or playlist here, then add it to a signage playlist like any other item.

These items need the internet. A screen skips one while it can't reach the site and shows it again when it can. A YouTube video plays muted unless the screen has Sound on.

Add a link

Relay checks the address when you add it: a site that refuses to be shown inside another page stays blank on screens, and a YouTube video whose owner turned embedding off can't play.

Set a playlist item's seconds to choose how long a web page or a playlist shows. A single YouTube video added with 0 seconds plays to its end; a number cuts it short. Removing a link here makes every playlist that uses it skip it.
