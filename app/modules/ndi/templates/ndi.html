Discovery server

A discovery server finds NDI sources across subnets and where multicast DNS is blocked. Point every NDI machine in the building at the same one (see the guide). Relay does not run one: NDI's licence does not allow bundling it, so install NDI Tools from ndi.video/tools on a computer that is always on.

The NDI runtime reads these settings when Relay starts. Restart Relay to apply the change.

Where to look

Multicast does not cross VLANs. Add the address of a machine on another VLAN, or turn on mDNS forwarding in your router, to see its sources. The NDI runtime is installed separately from ndi.video.
