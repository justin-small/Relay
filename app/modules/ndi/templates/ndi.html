Discovery server

A discovery server finds NDI sources across subnets and where multicast DNS is blocked. Point every NDI machine in the building at the same one (see the guide). Relay does not run one: NDI's licence does not allow bundling it, so install NDI Tools from ndi.video/tools on a computer that is always on.

The NDI runtime reads these settings when Relay starts. Restart Relay to apply the change.

Watching in a browser

Each source has a page at /ndi/view/<source> (the Watch link above) that plays it as a motion JPEG stream: on a booth laptop, a phone or a TV on this network. Anyone signed in who may see NDI can open it. Everyone watching one source shares one receiver. These limits keep a busy service from slowing Relay down.

A source with a camera number gets a red border on air and a green one on preview, from the tally state that ATEM, OBS and Tally Arbiter fill. Without the NDI runtime's audio, the level meter stays empty.

Multiviews

A multiview shows several sources at once on one page, /ndi/multiview/<name>, for a monitor or a TV on this network. Relay draws it once on the server however many people watch. Each box is a source (with a label, an audio meter and the tally border), a clock, or a countdown.

Router

A routed output is an NDI source called Relay - <name> that you point at any source here, like a video matrix. Set a TV or decoder to receive it once, then switch it from this page. The NDI library does the switching, so nothing is re-encoded. Routes are saved and come back when Relay restarts. Relay's own page outputs below are sources too.

Presets

Decoders such as the Magewell Pro Convert announce nothing and have a login-protected web API: point them at a routed output instead of driving them from here.

Page outputs

Send a Relay page out as an NDI source for a switcher, ProPresenter, OBS, vMix or a TV: each screen language, and overlays with transparency (key and fill in one source). Each one draws the page in a hidden browser, so switch on only what you use.

Where to look

Multicast does not cross VLANs. Add the address of a machine on another VLAN, or turn on mDNS forwarding in your router, to see its sources. The NDI runtime is installed separately from ndi.video.
