Parent paging

Kids workers page a parent from their room's page. The child's Check-Ins security code goes to a ProPresenter message; the child's name never leaves the room's page.

ProPresenter

In ProPresenter, make a message (for example "Parent of {code}, please come to the kids area") with a text token, and type its name and the token's name here. When several parents are paged at once, the token holds every code. The Test button on the Modules page checks both.

Each room gets its own link. Anyone with the link can page parents for that room only, with no sign-in, so hand it to that room's workers (a QR code on the wall works). It opens only on Relay's HTTPS address on this network, never through remote access. "New link" stops the old one at once.
