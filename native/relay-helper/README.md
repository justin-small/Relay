# Relay Helper

See [docs/helper.md](../../docs/helper.md). Part of the `native/` Cargo workspace (docs/rust-server.md). From `native/`: build with `cargo build --profile release-helper -p relay-helper`
(the binary is `target/release-helper/relay-helper`), test with `cargo test -p relay-helper`, then `cargo clippy --locked --all-targets -p relay-helper -- -D warnings`.
