Lighting redesign: three options

A. Tabbed workspace

Fire cues, Pages (editor), Screens (links and keys), Program. One job per tab; only the chosen program's fields show.

B. Lighting desk

The page fills the window like a console: pages on the left, big buttons and faders in the middle, screen link and recent presses on the right. Run / Edit layout toggle; setup in a drawer.

C. Page library

A setup checklist, then one card per page with a preview. Open a page to try it, edit it, and see its tablet screen and what uses it.
