One page per tool in the guide, linked from here. Each starts with “copy the link from the Build tab”.

OBS Studio

Browser source · canvas size (1920 × 1080) · transparent

  1. Sources → + → Browser, name it “Relay captions”.
  2. Paste the link into URL. Width and height = your canvas.
  3. Untick “Shutdown source when not visible” so captions don’t restart.
  4. Put it above your camera sources.

vMix

Add Input → Web Browser · 1920 × 1080 · transparent

  1. Add Input → Web Browser, paste the link.
  2. Set the size to 1920 × 1080.
  3. Put it on an Overlay channel (1–4) and turn it on for the stream output only.

ProPresenter

Web page on the Props layer · stream Look only

  1. Create a Prop with a Web Page object filling the slide; paste the link.
  2. In Looks, turn Props on for the stream screen and off for the room screens.
  3. Trigger the Prop at service start.

Blackmagic ATEM

Key + fill, or chroma green · output at switcher format

  1. Choose Key + fill on the Build tab; open the link full-screen on a computer feeding two ATEM inputs (fill and key), or use Chroma green on one input.
  2. Upstream key: Luma (key + fill) or Chroma (green).
  3. Turn the key on for program.
