NDI redesign: three options

A. One tab per feature

Sources, Cameras and tally, Multiviews, Router, Send Relay as NDI, Network. Each tab opens with one box saying what it is for.

B. In and out

Overview (in → screens → out, a setup checklist, problems), Coming in, Screens, Going out, Setup.

C. Source wall

Live picture grid; click a source to set its camera number, copy its link, see where it is used and send it to a TV. Outputs as a click grid.
