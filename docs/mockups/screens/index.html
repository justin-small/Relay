Core screens: what is the page for?

Issue #527. The point of one core screen per display: the operator can answer "what is on each TV right now, and how do I change it?" without knowing whether it is a board, signage or an alert, and each TV has one name and one place everywhere. A screen shows either a board page or a signage playlist, chosen by a schedule from the Schedules page; with Signage off it shows its board. Three takes on the page's main job. Data is made up.

A. Live wall: see it, then take over

Job: run the room now. Tiles show what each screen is displaying, grouped by place. Per tile: show this now, flash it, rename. Settings are secondary.

B. Plan grid: what each screen shows, when

Job: set it up once. One row per screen; columns are the situations (normally, during Sunday services, on alert). Pick a board or playlist in each cell.

C. Setup inbox: adopt new screens

Job: get a new TV onto Relay. New or unnamed displays appear on top with "Identify" (puts its temp name on the TV) and a quick name and place form; the rest is a plain list.
