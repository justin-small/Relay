# Part 2: Your OpenAI API key {.part}

Relay does not do the translation itself. It sends the room's audio to OpenAI,
and OpenAI sends back the English transcript and the translations. To do that,
Relay needs an **API key**: a long secret code that tells OpenAI which account
to bill.

This part shows you how to get a key, how to stop it costing more than you
expect, and how to give it to Relay. You only need to do most of this once.
