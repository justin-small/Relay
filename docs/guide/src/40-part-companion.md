# Part 4: Bitfocus Companion and Stream Deck {.part}

**Bitfocus Companion** is free software that turns a **Stream Deck** into a
control panel for the equipment in a room. A Stream Deck is a small keypad
with a screen behind each key. Many venues already use Companion to run
cameras, video switchers and lights.

The Relay module for Companion puts Relay on those keys. You can start and
stop captions, switch languages on and off, watch the microphone level and see
how long the session has run, without opening the operator panel.

This part is optional. Relay works fully without Companion. Read on only if
your venue uses Companion, or if you want physical buttons for Relay.
