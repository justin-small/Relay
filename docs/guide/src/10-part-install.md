# Part 1: Installing Relay {.part}

This part takes you from an empty computer to a running Relay. You download
one installer, open Relay, and create your account. Nothing else needs
installing first. There is one chapter for each kind of computer: macOS,
Windows and Linux. Read only the one you need.

Relay is an ordinary app. It starts when you open it, lives in the menu bar
(macOS) or the system tray (Windows, Linux), and can start by itself when you
log in. To stop it, quit it from that menu.

If you already run Relay 2.0, which used Docker, install the new version and
then read [Upgrading from Relay 2.0](#upgrading) to bring your settings across.
