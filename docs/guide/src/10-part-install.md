# Part 1: Installing Relay {.part}

This part takes you from an empty computer to a running Relay. You install
Docker, download Relay from GitHub, run the setup script once, and then start
Relay and open the operator panel. There is one chapter for each kind of
computer: macOS, Windows and Linux. Read only the one you need.

Remember one rule: **setup runs once, start runs every time.** You run setup
when you first install Relay, and again only to change your credentials. You
run start before every event.
