# Part 5: Caption panels {.part}

A **caption panel** is a small touch screen that shows Relay's captions on a
wall or a desk. People can read along without a phone. You set one up once,
then Relay looks after it.

This part is optional. Relay works fully without panels. Read on only if your
venue has bought a panel, or wants one.

This part also covers **Planning Center**, which shows the order of service on
a panel, and **Alerts**, which flash panels and screens when a musician needs
someone.
